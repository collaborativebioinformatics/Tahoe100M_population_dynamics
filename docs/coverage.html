Signature-search validation

Self-recall: for a sample of high-quality conditions, half of each signature's top genes were used as a query to see whether the tool ranks the original condition highly. Reversal recall checks that the sign-flipped query recovers it as a top reverser. Seed 42.

Scientific limitations. Response strength is a transcriptional-signature magnitude, not viability, killing, or clinical efficacy. Each condition tests the full gene universe, but low-expression genes are independent-filtered by DESeq2, so the finite gene set differs per condition — ranking therefore uses a mean-based robust RMS to stay comparable. The web signature index keeps only the top-K up/down genes per condition, so overlaps and cosines are top-K measures, not full-transcriptome correlations. Similarity scores are exploratory (no calibrated null model / p-value).
