Methods

How the real query tools are built

Every number in Explore, Compare, and Signature Search is derived from the Tahoe-100M pseudobulk differential-expression tables (1,026 shards, ~4.1 billion gene×condition rows). No demo or random values are used (is_demo: false).

1 · Input & direction

Each condition is a (cell line × drug × concentration × plate) tuple. The differential-expression contrast is treated − matched DMSO (DESeq2), so a positive log2 fold-change means the gene is up-regulated by the drug. Direction was confirmed biologically — e.g. Bortezomib (a proteasome inhibitor) shows the expected heat-shock induction (HSPA6, HSPA1A/B) as its strongest up genes. The full gene universe (62,710 genes) is tested per condition; low-expression genes are independent-filtered by DESeq2 and appear as null log2FC, so the finite gene set differs slightly between conditions.

2 · Response magnitude

Transcriptional response strength = robust RMS of the winsorized log2 fold-changes across a condition's tested genes: rms = sqrt(mean(clip(log2FC, ±cap)²)). The winsor cap is the global 99.5th percentile of |log2FC| (seed 42 subsample of shards) so a few extreme genes cannot dominate. RMS is mean-based, so conditions with different numbers of filtered genes remain comparable — a raw L2 norm (also stored as response_magnitude_l2) is not comparable across conditions and is not used for ranking. This is not drug sensitivity, viability, killing, or clinical efficacy.

3 · Signatures & search

For every condition we keep its top up- and top down-regulated genes (top-200 for profiles; the browser search index uses top-K per direction, recorded in meta.json). Each gene's signed weight is its winsorized log2FC × inverse-document-frequency (IDF), where IDF down-weights genes that appear in many conditions' signatures (common stress / cell-cycle programs). Weights are L2-normalized per condition. A query scores each condition as the signed dot product of query genes (+1 up, −1 down) with the condition's signature: positive = similar, negative = candidate reversal. Because the index is truncated to top-K, all overlaps and cosines are labelled top-K signature measures, never full-transcriptome correlations. Scores are exploratory — there is no validated null model, so no p-values are reported.

4 · Replicate reliability

When the same cell line × drug × dose was measured on two plates, we report the agreement of their signatures (top-K cosine and Spearman over shared genes) as a separate QC badge. It is never folded into the response-strength ranking. See Coverage & QC for the validation numbers.

5 · Static, free deployment

The site is fully static (GitHub Pages). All three tools run in the browser with no server, database, or paid API: selector metadata and per-drug/per-cell rankings are small JSON; per-condition profiles are sharded JSON loaded on demand; the signature search uses a compact binary sparse inverted index (Int32 condition ids + Float32 weights) that scores all conditions client-side in well under a second. Large derived files are hosted separately (e.g. Hugging Face) and are not committed to Git. The data base URL is configurable in assets/config.js, via ?data=, or localStorage.

Reproducibility: analysis ran on the University of Iowa Argon SGE cluster (qsub). See METHODS.md, DATA_DICTIONARY.md, LIMITATIONS.md, and DEPLOYMENT.md in the repository.
