Query signature

Paste at least 3 recognized genes and press Search.
Method & limits. Each condition is represented by its top-K up/down DE genes, weighted by winsorized log2FC × inverse document frequency (so ubiquitous stress/cell-cycle genes don't dominate), and L2-normalized. Query up genes count +1, down genes −1; the match score is their signed dot product with each condition. Positive = similar signature; negative = candidate reversal. This is an exploratory similarity score, not a calibrated statistic — there is no validated null model, so no p-values are shown. Results with only 1–2 overlapping genes are de-ranked and flagged.
