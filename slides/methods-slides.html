01 · Pipeline

How the tool reads a population

Every drug × cell line × dose condition is designed to run the same four-stage read, then repeat across the whole dataset.

  • Input. Per-cell response scores and plate / well / drug / dose / DMSO-role metadata from the H5AD, plus precomputed pseudobulk summaries in Parquet for the interactive site.
  • Magnitude — median difference from DMSO, standardized by the DMSO median absolute deviation. Coverage — fraction of treated cells outside the DMSO-calibrated reference interval; residual fraction is the complement.
  • Dispersion check — does treatment shift, widen, compress, or split the distribution. QC sensitivity check — tests whether the residual fraction tracks RNA depth, detected genes, mitochondrial fraction, cell-cycle state, or sample identity.

Status

  • Pairwise dose-vs-DMSO comparison is designed to run across every condition — but the pipeline has not yet been run on real Tahoe single-cell data.
  • The live 65,218-condition public Atlas is a separate, already-real pseudobulk analysis — magnitude only, no completeness claim.

02 · Statistical design

One rule, frozen before it sees plate 14

A two-plate evidence-ladder design: plate 6 sets every parameter; plate 14 is examined only after the rule is frozen.

  • On plate 6, independent DMSO samples are assigned calibration and held-out negative-control roles — where the metadata confirms the design — never pooled.
  • The response score is not yet frozen. A pathway or mechanism-of-action score is the preferred starting point; the exact score, reference-interval alpha, and QC rules remain to be selected using plate 6 only.
  • DMSO-vs-DMSO and treatment-vs-DMSO comparisons run in parallel; cell counts, QC variables, and every threshold get logged.
  • The full rule — score definition, DMSO roles, reference interval, QC cutoffs — is frozen before plate 14 is opened; plate 14 must not be inspected for parameter selection if it's retained as validation.

Caveats we state explicitly

  • Wilson intervals describe within-sample uncertainty in a cell fraction, not biological replication — that comes from the plate 6/14 comparison.
  • Current replicate matches mainly cover the high-dose condition, not a full dose series — dose-consistency is stated as its own claim.

03 · Implementation

Tested code, one schema, two homes

Heavy compute stays where the data lives; everything reusable ships in the open.

  • The public site now has two distinct parts: a real pseudobulk Atlas (65,218 conditions) and an illustrative single-cell response-completeness interface.
  • The Atlas is valid but does not estimate residual fractions or cell-level heterogeneity — that's what the response-completeness pipeline is for.
  • Heavy per-cell compute runs on the team’s DNAnexus project; only aggregate results leave it. Reusable code, tests, and Methods text stay on GitHub.
  • Once computed, a real result exports to the same versioned JSON schema the interface already reads — swapping in for the illustrative demo without a redesign.

  • Exact score and calibration configuration: pending metadata inspection.
  • First real plate-6 run: not yet completed.
